# tpt-elec-semi-process

> Process design kit abstractions: interconnect RC, vias, and design rules

Part of [tpt-electronics](https://github.com/tpt-solutions/tpt-electronics) — a fully open-source, MIT-licensed multiphysics simulation engine.

`pdk` · `technology-node` · `interconnect` · `electromigration` · `design-rules`

## Status

✅ Stable · Part of the v0.1.0 release

## Usage

Add to your `Cargo.toml`:

```toml
[dependencies]
tpt-elec-semi-process = "0.1.0"
```

See the crate-level documentation for a tested quick-start example.

## Testing

```console
$ cargo test -p tpt-elec-semi-process
```
