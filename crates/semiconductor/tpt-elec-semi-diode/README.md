# tpt-elec-semi-diode

> Diode compact model: Shockley equation, junction capacitance, and reverse breakdown

Part of [tpt-electronics](https://github.com/tpt-solutions/tpt-electronics) — a fully open-source, MIT-licensed multiphysics simulation engine.

`diode` · `shockley` · `junction-capacitance` · `series-resistance` · `breakdown`

## Status

✅ Stable · Part of the v0.1.0 release

## Usage

Add to your `Cargo.toml`:

```toml
[dependencies]
tpt-elec-semi-diode = "0.1.0"
```

See the crate-level documentation for a tested quick-start example.

## Testing

```console
$ cargo test -p tpt-elec-semi-diode
```
