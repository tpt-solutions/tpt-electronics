# tpt-elec-si-impedance

> Characteristic impedance: Hammerstad-Jensen microstrip, stripline, differential pair, and inverse solver

Part of [tpt-electronics](https://github.com/tpt-solutions/tpt-electronics) — a fully open-source, MIT-licensed multiphysics simulation engine.

`impedance` · `microstrip` · `stripline` · `hammerstad-jensen` · `differential`

## Status

✅ Stable · Part of the v0.1.0 release

## Usage

Add to your `Cargo.toml`:

```toml
[dependencies]
tpt-elec-si-impedance = "0.1.0"
```

See the crate-level documentation for a tested quick-start example.

## Testing

```console
$ cargo test -p tpt-elec-si-impedance
```
