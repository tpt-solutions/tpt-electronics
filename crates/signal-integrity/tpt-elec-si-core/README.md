# tpt-elec-si-core

> Transmission line models, S-parameters, and shared signal-integrity data structures

Part of [tpt-electronics](https://github.com/tpt-solutions/tpt-electronics) — a fully open-source, MIT-licensed multiphysics simulation engine.

`signal-integrity` · `transmission-line` · `s-parameters` · `impedance` · `reflection`

## Status

✅ Stable · Part of the v0.1.0 release

## Usage

Add to your `Cargo.toml`:

```toml
[dependencies]
tpt-elec-si-core = "0.1.0"
```

See the crate-level documentation for a tested quick-start example.

## Testing

```console
$ cargo test -p tpt-elec-si-core
```
