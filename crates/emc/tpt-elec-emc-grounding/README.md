# tpt-elec-emc-grounding

> Grounding and return-path modeling: plane impedance, slot crossings, loop coupling

Part of [tpt-electronics](https://github.com/tpt-solutions/tpt-electronics) — a fully open-source, MIT-licensed multiphysics simulation engine.

`grounding` · `return-path` · `slot-coupling` · `ground-loop` · `impedance`

## Status

✅ Stable · Part of the v0.1.0 release

## Usage

Add to your `Cargo.toml`:

```toml
[dependencies]
tpt-elec-emc-grounding = "0.1.0"
```

See the crate-level documentation for a tested quick-start example.

## Testing

```console
$ cargo test -p tpt-elec-emc-grounding
```
