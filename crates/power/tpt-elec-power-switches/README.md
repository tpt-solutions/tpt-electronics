# tpt-elec-power-switches

> Power switch and rectifier loss models: conduction, switching, gate drive, and thermal

Part of [tpt-electronics](https://github.com/tpt-solutions/tpt-electronics) — a fully open-source, MIT-licensed multiphysics simulation engine.

`mosfet` · `diode` · `switching-loss` · `conduction-loss` · `gate-charge`

## Status

✅ Stable · Part of the v0.1.0 release

## Usage

Add to your `Cargo.toml`:

```toml
[dependencies]
tpt-elec-power-switches = "0.1.0"
```

See the crate-level documentation for a tested quick-start example.

## Testing

```console
$ cargo test -p tpt-elec-power-switches
```
